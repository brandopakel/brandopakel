# Brando Pakel

Systems-minded engineer building **[Omnivest](https://github.com/brandopakel/omnivest-architecture)** — an institutional
portfolio-intelligence and autonomous research platform: 1.6M lines of Python
orchestrating 27 native services in **Go, Rust, C++, and OCaml**, running
local-first on a single workstation with a continuous, evidence-governed
learning loop.

The Omnivest source is private; the architecture, engineering doctrine, and a
**live paper track record** (NAV badges published hourly by the platform
itself) are documented in
[omnivest-architecture](https://github.com/brandopakel/omnivest-architecture).

## What I care about in software

- **Fail-closed authority** — when required data or credentials are missing,
  systems should stop, not guess.
- **Measured over assumed** — fees, schemas, thresholds, and costs read from
  the source of truth, never hardcoded.
- **Native code where it counts** — Go for dispatch and data planes, Rust for
  kernels, C++ for execution machinery, OCaml for independent verification of
  quantitative results.
- **Evidence-governed learning** — strategy changes ship like releases:
  immutable artifacts, incumbent-relative gates, atomic rollback.
